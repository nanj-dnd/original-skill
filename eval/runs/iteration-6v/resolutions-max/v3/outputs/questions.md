## What everyone gets

Main claim: resolutions fail because they're vague, too ambitious and powered by willpower, so set specific, small, habit-based goals instead.

Choices it makes:
- **Thesis:** the problem is how people set goals (vague, too big, willpower-dependent).
- **Evidence:** the "80% quit by February" stat plus a nod to habit research.
- **Structure:** 3 to 5 reasons they fail, then matching tips (SMART goals, start small, track progress).
- **Reader:** a generic self-improver who's never thought about it.
- **Tone:** upbeat, encouraging explainer.
- **Leaves out:** the writer's own experience, and whether making resolutions is worth doing at all.
