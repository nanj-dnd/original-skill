**Fixed parts:** any statistic about how many resolutions fail (the common "80% fail by February" or "only 8% succeed" figures are poorly sourced; I can't check them here, so I'd mark any I use as unchecked), plus the ~400-word length. **Open:** the claim, the angle, examples, structure, the reader, and how it ends.

## What everyone gets

Main claim: most resolutions fail because they're too vague, too ambitious and run on willpower, so set small, specific, habit-based goals instead.

Choices it made:
- **Thesis:** the fault is in how resolutions are designed (vague, huge, willpower-driven).
- **Examples:** the January gym rush, an "80% quit by February" stat, "Quitter's Day" in mid-January.
- **Structure:** hook stat, then 3 to 5 reasons, then tips (SMART goals, start small, track it).
- **Reader:** a generic self-improvement reader, upbeat self-help tone.
- **Ending:** encouraging, "you can do it this year."
- **Leaves out:** the writer's own experience, and whether failing a resolution is actually bad.
