# Pilot test of this skill (v1), November 2026

2 open tasks (an all-hands talk, a blog post) × 4 hand-written personas × 4 arms, judged blind.

| Arm | Distinct main ideas across 4 users | Judge picked the right user | Quality (1–5) |
|---|---|---|---|
| Plain model | 1 | chance | 4.0–5.0 |
| Plain model + answers to this skill's questions | 4 | 4/4 | 4.0–4.2 |
| Skill, quick mode (no questions) | 3–4 | chance | 4.2–4.8 |
| Skill, full (questions + shortlist + pick) | 4 | 4/4 | 4.0–4.2 |

- With no skill, every user got the same answer.
- The full skill and "plain model + the same answers" landed on the same main idea for 8 of 8 personas. The shortlist step added a user turn and about 3× the tokens without changing the main claim.
- Quick mode moved off the default but not toward the user: different, not theirs.
- Users with default-matching positions still got distinct, well-fitted outputs when they supplied specifics (a case, a number, a constraint).
- Users engaged with the "strongest objection" and "test" lines and corrected their own claims because of them.

Limits: 4 outputs per arm per task, one judge run each, model-written personas with unusually clear views, and the "plain + answers" arm used this skill's own questions. Not tested: whether the shortlist helps users with vague views, and whether generic clarifying questions would do as well as these.
