# Pilot tasks

Both are open tasks where a plain model has a strong default.

## talk
I've got 5 minutes at our company all-hands next Friday to talk about whether engineers should be using AI coding assistants for everything. Can you write me an outline and the opening paragraph?

Expected default: "AI assistants are powerful tools but need human oversight." Use them for boilerplate and tests, review everything, balance productivity against risk, invest in upskilling. Pro/con structure, written for engineers.

## resolutions
Write me a ~400-word blog post on why most New Year's resolutions fail. It's for my personal blog.

Expected default: "Resolutions fail because they're vague, too big and rely on willpower; build systems and habits instead." SMART goals, Atomic Habits, start small, track progress, be kind to yourself, written for a general self-improvement reader.
